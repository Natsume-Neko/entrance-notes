1. Microarchitecture
	Microarchitecture is the detailed design and implementation of a CPU's internal structure that defines how it executes instructions. It sits between the processor's architecture (instructure sets and features) and the underlying hardware. It specifies the internal components like ALU, registers, memory and pipelines and their interconnections. It also defines how they interact to process instructions, memory access, branches and so on. For example, consider 2 CPUs with the same architecture (e.g. x86), they can implement different microarchitectures, possibly one with high performance and the other is power-efficient.
2. Binary Translation
	Binary Translation is a technique that translates binary code from one instruction set architecture to the other. It enables software written for one instruction set architecture to be executed in the other without recompilation of source code. For example, if we want to run an x86 program on an ARM processor, we can exploit binary translation to translate the x86 instructions to ARM instructions, which enables cross-platform compatibility. It is widely used in virtualization, emulation and legacy software support.
