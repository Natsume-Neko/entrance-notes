## Boosting
Boosting is a machine learning technique. It learns multiple weak learners and combines them to form a stronger predictive model. The weak learners in boosting are often simple models like decision tree with limited depth, which are trained sequentially. Each weak learner will try to correct the errors made by previous one, focusing more on the data points that are misclassified by the earlier models. The final stronger models are formed by take a linear combination of the weak learners. The examples include Adaboost and Boosting Tree. 
## KNN
K-nearest neighbor is a fundamental machine learning method for both classification and regression. It predicts or classifies by indentifying the $k$ closest data points in the sample space to the new data point, and uses the majority vote machenism for classification or the value average for regression as the result. This algorithm is sensitive to the choice of $k$. If $k$ is too small, the model may overfit. If $k$ is too large, the model prones to underfit. The closest data points are determined by the distance metric, which can be Euclidean Distance, Manhattan Distance and so on. And to improve the calculation efficiency, KD-Tree may be employed.
## Logistic Regression
Logistic Regression is a kind of classification model in machine learning. It operates by estimating probabilities using a logistic function, which is an $S$ shaped curve that maps any real value number into the range 0 to 1. In binominal logistic regression, which solves binary classification problem, the probability $P$ it predicts can be expressed as $P(Y=1|x)=\frac{e^{\omega x + b}}{1 + e^{\omega x + b}}$ , where $\omega$ and $b$ are the parameters of the model, $x$ is the input and $Y$ is output. It can also solve multi-classification problem using multi-nominal logistic regression. To find the best parameters, it employs maximum likelihood estimation. Once the model is trained, it calculates the probability and classifies the input using the output with the maximum probability.
## Perceptron
Perceptron is a kind of linear binary classification model in machine learning. It takes input features $x$ and calculates the output $y = h(\omega \cdot x + b)$, where $y$ represents the predicted class of $x$, $h$ is the activation function, $\omega$ and $b$ are the parameters of the model. Assume the datapoints are linearly separatable, Perceptron would find a hyperplane which separates the datapoints. To train the model, gradient descent is employed. Percetron is the base of Support Vector Machine and Neural Networks.
## K-means
K-means is a machine learning method for cluster problem, which belongs to unsupervised learning. K-means works iteratively to find the cluster result, which would reach a local optimal but not global optimal. The algorithm would randomly choose $k$ data points as the cluster centers, cluster the data points into the cluster with the closest distance (where the distance is determined by the Euclidean distance between the cluster center and the data point), then find the new cluster centers by taking the average of the data points in each cluster, and repeat the procedure iteratively until converge. Since K-means cannot ensure find the global optimal, the random choice of the original $k$ centers can lead to different final results.
